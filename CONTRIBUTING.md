# Contributing

Public papers, implementation links and corrections are welcome.

For each entry, provide its title, DOI or primary publication URL, method name, year, principal task and computational components. Add implementation links with the publication's code-availability statement or an author-repository source. Label third-party reproductions separately.

The three primary method tasks are state representation learning, perturbation-response prediction, and intervention discovery and design. Mention demonstrated connections to other tasks and include the measured modalities where applicable.

Edit the relevant entries directly in [README.md](README.md), or open an issue with the proposed addition or correction. Keep the existing entry format and place each method under its principal task. The optional static website stores its catalogue in `assets/catalog.js`; update the matching entry there when changing the website.

Link to original publications, datasets and implementations.
