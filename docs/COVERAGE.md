# Catalogue contents and link sources

Updated 22 October 2026.

- 241 public literature and resource records.
- 85 state representation entries, 69 perturbation-response entries, and 9 intervention/design entries. The design section includes seven intervention methods and two closed-loop experiment-selection examples.
- 35 experimental/data resources, 23 benchmark/evaluation records, 3 background reviews and 17 additional resources.
- 151 records include implementation links.

Each record contains bibliographic information, task labels and links to the original publication. Implementation records include a publication or author-repository evidence URL. Link-check dates describe when those sources were inspected.

The main reading list is maintained directly in [README.md](../README.md). The optional static website stores its catalogue in `assets/catalog.js`. To suggest additions or corrections, see [CONTRIBUTING.md](../CONTRIBUTING.md).
